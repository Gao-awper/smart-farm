# 智慧农场预览界面从数据库读取数据方案

## 一、前端界面修改

### 1. 创建API服务层

首先，创建一个API服务层来封装与后端的通信：

```javascript
// src/api/farmApi.js
import axios from 'axios';

// 创建axios实例
const apiClient = axios.create({
  baseURL: 'http://localhost:8080/api', // 后端API基础URL
  timeout: 10000, // 请求超时时间
  headers: {
    'Content-Type': 'application/json'
  }
});

// 农场概览API
export const getFarmOverview = () => {
  return apiClient.get('/farm/overview');
};

// 实时监测数据API
export const getRealtimeData = () => {
  return apiClient.get('/farm/realtime');
};

// 土壤数据API
export const getSoilData = () => {
  return apiClient.get('/farm/soil');
};

// 气象数据API
export const getWeatherData = () => {
  return apiClient.get('/farm/weather');
};

// 灌溉数据API
export const getIrrigationData = () => {
  return apiClient.get('/farm/irrigation');
};

// 作物数据API
export const getCropsData = () => {
  return apiClient.get('/farm/crops');
};

// 数据分析API
export const getAnalysisData = (params) => {
  return apiClient.get('/farm/analysis', { params });
};
```

### 2. 修改Home.vue组件

将静态数据替换为从API获取的数据：

```javascript
// src/components/Home.vue
<script setup>
import { ref, onMounted } from 'vue';
import { getFarmOverview, getRealtimeData, getSoilData, getWeatherData } from '../api/farmApi';

// 核心状态
const farmOverview = ref({}); // 农场概览数据
const realtimeData = ref({}); // 实时监测数据
const soilData = ref({}); // 土壤数据
const weatherData = ref({}); // 气象数据
const loading = ref(false); // 加载状态
const error = ref(null); // 错误信息

// 加载农场概览数据
const loadFarmOverview = async () => {
  try {
    loading.value = true;
    const response = await getFarmOverview();
    if (response.data.success || response.data.status === 'success') {
      farmOverview.value = response.data.data;
    } else {
      error.value = '加载农场概览失败';
    }
  } catch (err) {
    error.value = '加载农场概览失败';
    console.error(err);
  } finally {
    loading.value = false;
  }
};

// 加载实时监测数据
const loadRealtimeData = async () => {
  try {
    loading.value = true;
    const response = await getRealtimeData();
    if (response.data.success || response.data.status === 'success') {
      realtimeData.value = response.data.data;
    } else {
      error.value = '加载实时监测数据失败';
    }
  } catch (err) {
    error.value = '加载实时监测数据失败';
    console.error(err);
  } finally {
    loading.value = false;
  }
};

// 加载土壤数据
const loadSoilData = async () => {
  try {
    const response = await getSoilData();
    if (response.data.success || response.data.status === 'success') {
      soilData.value = response.data.data;
    }
  } catch (err) {
    console.error('加载土壤数据失败:', err);
  }
};

// 加载气象数据
const loadWeatherData = async () => {
  try {
    const response = await getWeatherData();
    if (response.data.success || response.data.status === 'success') {
      weatherData.value = response.data.data;
    }
  } catch (err) {
    console.error('加载气象数据失败:', err);
  }
};

// 初始化数据
onMounted(() => {
  loadFarmOverview();
  loadRealtimeData();
  loadSoilData();
  loadWeatherData();
  
  // 每30秒刷新一次实时数据
  setInterval(() => {
    loadRealtimeData();
  }, 30000);
});
</script>
```

### 3. 添加加载状态和错误处理

在模板中添加加载状态和错误提示：

```html
<!-- 加载状态 -->
<div class="loading-overlay" v-if="loading">
  <div class="loading-spinner">加载中...</div>
</div>

<!-- 错误提示 -->
<div class="error-message" v-if="error">
  {{ error }}
  <button @click="error = null">关闭</button>
</div>
```

## 二、数据库设计

### 1. 数据库表结构

#### 1.1 作物表（crops）

```sql
CREATE TABLE crops (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL, -- 作物名称
    type VARCHAR(50) NOT NULL, -- 作物类型
    area DECIMAL(10, 2) NOT NULL, -- 种植面积（亩）
    status VARCHAR(50) NOT NULL, -- 生长状态
    expectedHarvest DATE NOT NULL, -- 预计收获日期
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

#### 1.2 灌溉区域表（irrigation_zones）

```sql
CREATE TABLE irrigation_zones (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL, -- 区域名称
    area DECIMAL(10, 2) NOT NULL, -- 区域面积（亩）
    status VARCHAR(50) NOT NULL, -- 状态
    lastIrrigation DATETIME, -- 上次灌溉时间
    nextIrrigation DATETIME, -- 下次灌溉时间
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

#### 1.3 设备表（devices）

```sql
CREATE TABLE devices (
    id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL, -- 设备名称
    type VARCHAR(50) NOT NULL, -- 设备类型
    status VARCHAR(50) NOT NULL, -- 设备状态
    location VARCHAR(100) NOT NULL, -- 设备位置
    lastOnline DATETIME, -- 最后在线时间
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

#### 1.4 用户表（users）

```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    nickname VARCHAR(100) NOT NULL, -- 用户名
    email VARCHAR(100) UNIQUE NOT NULL, -- 邮箱
    password VARCHAR(255) NOT NULL, -- 密码
    phone VARCHAR(20), -- 电话
    sex VARCHAR(10), -- 性别
    identity VARCHAR(50) NOT NULL, -- 身份（admin/regular）
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

#### 1.5 监测数据表（monitoring_data）

```sql
CREATE TABLE monitoring_data (
    id INT PRIMARY KEY AUTO_INCREMENT,
    type VARCHAR(50) NOT NULL, -- 数据类型（土壤湿度、温度等）
    value DECIMAL(10, 2) NOT NULL, -- 数值
    unit VARCHAR(20) NOT NULL, -- 单位
    location VARCHAR(100) NOT NULL, -- 采集位置
    device_id INT, -- 设备ID
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (device_id) REFERENCES devices(id)
);
```

## 三、后端API设计（简要）

### 1. 农场概览API

- `GET /api/farm/overview` - 获取农场概览数据

### 2. 实时监测API

- `GET /api/farm/realtime` - 获取实时监测数据

### 3. 土壤数据API

- `GET /api/farm/soil` - 获取土壤数据

### 4. 气象数据API

- `GET /api/farm/weather` - 获取气象数据

### 5. 灌溉数据API

- `GET /api/farm/irrigation` - 获取灌溉数据
- `POST /api/farm/irrigation/control` - 控制灌溉系统

### 6. 作物数据API

- `GET /api/crops` - 获取作物列表
- `POST /api/crops` - 添加作物
- `PUT /api/crops/:id` - 更新作物
- `DELETE /api/crops/:id` - 删除作物

### 7. 设备数据API

- `GET /api/devices` - 获取设备列表
- `PUT /api/devices/:id/status` - 更新设备状态

### 8. 用户API

- `POST /api/register` - 用户注册
- `POST /api/login` - 用户登录
- `GET /api/users` - 获取用户列表

## 四、技术栈建议

### 前端

- Vue 3 + Composition API
- Axios（HTTP客户端）
- Vue Router（路由管理）

### 后端

- Node.js + Express（后端框架）
- File System（文件存储，适合小型项目）
- MySQL（数据库，适合大型项目）
- JWT（可选，用于身份验证）

### 部署

- 前端：Nginx
- 后端：Node.js 服务器
- 数据库：MySQL（可选）
